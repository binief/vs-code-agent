MCP servers

MCP (Model Context Protocol) servers add their tools to the agent, prefixed mcp_<server>_<tool>. A stdio server is a command the editor spawns and talks to over its stdin/stdout; http and sse servers are reached over the network at a https:// endpoint — Streamable HTTP by default, with automatic fallback to the older SSE transport (or force one via the type selector).

Stdio example: npx -y @modelcontextprotocol/server-filesystem .
HTTP example: url: https://mcp.example.com/mcp with header Authorization: Bearer …

These settings live in codingHarness.mcp.*. Servers are also read from .vscode/mcp.json, .mcp.json and mcp.json; those appear read-only above and settings override a file entry with the same name. Servers (re)connect on save or via Reload.
