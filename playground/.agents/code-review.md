This file is here to show that the name does not matter: every Markdown file inside
`.agents/` is loaded as instructions, so `code-review.md` works exactly like `agent.md`.

When reviewing `src/`:

- Read the diff, then point out real defects (wrong totals, missing rounding) before style nits.
- Quote the smallest snippet that shows the problem and say what the correct behaviour should be.
