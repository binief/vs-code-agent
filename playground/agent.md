# Playground instructions

This is a scratch project for trying the extension. The instructions below are examples — replace
them with whatever you want the agent to do here.

## Project

- Plain JavaScript, no build step, no dependencies.
- `src/cart.js` contains the cart logic; `package.json` only holds the test script.

## Commands

- Run `npm test` after changing `src/cart.js`.

## Conventions

- Keep the code dependency-free and in the existing style (2-space indentation, semicolons).
- Add a short comment above any non-obvious calculation.
